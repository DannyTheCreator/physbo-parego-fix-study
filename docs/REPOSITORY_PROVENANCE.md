# Independent repository provenance

This repository was created on 16 October 2026 for the two VLMOP2 experiments
described in the README: the controlled ParEGO correction effect and the native
fixed-evaluation-budget comparison. Its default branch is `main`.

The initial source is the committed two-experiment tree at
`7ee7aeb7d3f12cf390a79293f64317488ad9211d` from the former
`DannyTheCreator/physbo-budget-benchmark` repository. A new Git history starts
here. Earlier release numbers and source commit identities in historical
evidence describe the predecessor project; they are not releases or commits
in this new repository. Historical acquisition snapshots remain unchanged.

All 120 retained trajectory files were copied with identical SHA-256 hashes.
The 6,000 recorded evaluations, scientific results and original timings were
not regenerated for this migration. Citation URLs now identify this repository.
The source tree and predecessor Git refs are backed up locally before deletion.

Earlier validation is documented in [VALIDATION.md](VALIDATION.md) and its
linked evidence. CI for this new repository is independent of predecessor CI.
The incomplete semantic review remains incomplete.

On 16 October 2026, the owner requested deletion and recreation of this same
GitHub repository to correct contributor attribution. The complete project,
including the expanded README, was republished with a new root commit authored
and committed as `DannyTheCreator`, using that account's GitHub noreply address.
The earlier local Git history, repository metadata and project archive were
backed up before deletion. Historical evidence retains its original identities.

This identity correction does not rerun or alter the original experiments.
The 120 retained trajectory files were checked against their pre-recreation
SHA-256 hashes. Validation recorded before recreation remains historical
evidence; the recreated repository has its own CI execution.
