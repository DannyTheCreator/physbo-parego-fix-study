# Attribution and project work

PHYSBO maintainers supply the algorithms and official ParEGO correction.
The project does not claim authorship or discovery of that fix. VLMOP2 and
the optimization strategies predate this project.

The project supplies a controlled operator-effect experiment and a native
fixed-budget strategy comparison, with paired initialization, repeated seeds,
auditable trajectories and reproducible reports. The operator diagnostic is
not a complete comparison between released software versions. Native ParEGO
uses a different weight mechanism from the diagnostic branch.

Implementation, analysis and writing were AI-assisted. Earlier releases and
their citation metadata describe earlier scope. Current citation metadata
names this two-experiment study; cite the commit used. Retained observations
are preserved, and scope-projection metadata does not imply a new experiment
execution. Final validation and review are recorded separately.
